# Tienda en línea con AngularJS

Desafío Práctico 2 - Lenguajes Interpretados en el Cliente (LIC941)
Universidad Don Bosco

Tienda en línea hecha con AngularJS que muestra productos consumidos desde un servicio web,
con filtros por categoría y nombre, modal de detalles y carrito de compra.

## Cómo ejecutarlo
Abrir `index.html` en el navegador (necesita internet para cargar AngularJS, Bootstrap y los productos).

## Estructura
- `index.html` - página principal de la tienda
- `css/estilos.css` - estilos propios
- `js/app.js` - módulo de AngularJS
- `js/productoService.js` - servicio que consume el JSON de productos con $http
- `js/tiendaController.js` - controlador: productos, categorías, filtros, detalles y carrito
- `images/` - imágenes del slider

## Servicio web
https://fakestoreapi.com/products

## Tecnologías
HTML5, CSS3, Bootstrap 4.6 y AngularJS 1.8
